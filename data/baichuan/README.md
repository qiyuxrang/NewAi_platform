# 百川企业数据交付快照

本目录是当前所属本地百川库的可检查数据快照。用户已明确同意将企业数据上传至现有公开 GitHub 仓库；任何访问者均可下载本目录。账号、密码、密钥、会话、模型配置、对话、用户上传的招标附件及运行数据库不在此快照中。

## 内容

- `companies.csv`：1,283 家企业的当前完整字段，UTF-8 BOM，可直接用 Excel 查看。
- `tables/*.jsonl`：9 张业务表、25,843 条记录；保留企业 ID、原值、来源、版本、资质、证书、事实修订、规则及研究状态。
- `manifest.json`：字段定义、原表结构、行数、内容摘要、文件哈希和非空字段计数。
- `source-index.json` 与 `sources/*.gz`：4,064 个已有来源文件路径，按内容去重为 1,754 份 gzip 内容；包括原始及整理 Excel、既有研究正文和源表核对资料。文件原名、原类型和内容 SHA-256 可由索引追溯；不必联网或再次调用模型。
- `validation.json`：本次真实回读校验结果。

当前 1,460 条旧资质按用户确认的旧库可信策略用于检索。证书表共 1,622 条，其中新增公开观察不自动继承旧库信任；原核实状态、主体、期限和冲突字段全部保留。官网非空 105 家，电话非空 1,035 家，地址 270 家，邮箱 115 家。这些数字是字段非空计数，不代表全库资料已补齐或全部字段已独立核实。

此库来源为本轮用户提供的原 Excel 及已完成的本地维护；不是已找回的历史官网研究数据库。资料补全和速度目标仍按用户要求延期；上传 GitHub 不代表正式部署。

## 校验和读取

从仓库根目录执行（仅需 Python 3.11+ 标准库，无网络、模型和数据库写入）：

```powershell
python scripts/baichuan/export_repository_data.py --verify data/baichuan
```

JSONL 每行一个完整原始记录；空值、UNKNOWN、验证状态和日期均不重新解释。来源文件通过 `source-index.json` 的 `blob` 找到，使用 `gzip.decompress()` 读取并对照 `sha256`。其中保存的原 `.runtime/...` 路径只是历史来源定位，不是仓库外文件访问指令。

本快照不含应用用户和研究任务的执行行；审计 actor/job ID 保留为外部引用。AI-D41 新增 `scripts/baichuan/restore_repository_data.py`：默认只校验，显式执行仅接受专用新空库、映射指定审计操作员、建立取消的研究归档引用，备份后事务导入并完整回读；非空库拒绝覆盖，不自动继续研究。步骤与边界见[换机说明](../../doc/github-local-update.md)。没有对任何现用库清空、重建或覆盖。

第三方网页、政府/行业材料及原始资料的权利归原权利人；仓库代码许可证不自动改变这些资料的许可范围。来源内容是历史归档，可能包含当时的失败页或不可访问记录，不据此判定企业没有相应资质。
