## 资料与生成方式

联网核实 PostgreSQL 故障转移及归档恢复、Kafka Connect、Great Expectations、OWASP 日志与授权、NIST 零信任、Prometheus 告警，共八份官方来源。核实日期、网址、版本范围、简要摘要、章引用与 SHA256 见 `.runtime/company-test/core/triad-web-research/manifest.json`。只作通用技术参考，不证明本项目现状、选型、容量或财务可行性。

八份参考加一份合成项目事实通过正常业务 API 上传并绑定章节，目录、原条件与待确认资料保留。联网检索由 Codex 外部完成，业务自动联网适配器未配置；本轮未访问 RAGFlow。

真实模型为 `qwen3.8-flash`，通过业务 Worker 和私有模型网关调用，无响应替身。批准的是八章蓝图及来源引用版本；正式发布关闭。技术方案正文非空白字符至少 50000，可研至少 70000；输出技术方案 DOCX、可研 DOCX、PPTX。预算、工期、接口、数据规模及网络拓扑仍待确认，不能将草稿当作已批准的正式成果。
