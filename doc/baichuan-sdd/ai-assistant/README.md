## 核心决策

1. 默认收起为右下角小角色。点击打开覆盖列表右侧的半透明面板，列表不被挤窄；一个输入区支持文字和附件，无模式选择。
2. 自动执行文字检索或文件拆解；必要时只在同一对话内询问确实影响结果的歧义，不增加固定确认步骤。
3. 按用户最新要求，查询只使用已入库资料，不在使用过程中自动补齐；独立资料研究现按用户要求暂停。旧资质按AI-D28用户确认的旧库事实检索。企业检索以结构化数据和确定规则执行，AI 负责理解、提取与解释。
4. 现有表结构做增量扩展，保留现有列表、详情、手工维护、企业 ID 和整理成果。不会重建企业库。
5. 原计划的全库资料补全现按用户要求延期，历史清单保留；“全部企业已研究”与“全部字段已有可靠信息”分别计量。
6. 采用用户原图透明背景及柔和阴影的表现方式。它是二维素材；真实 3D 模型作为后续可选升级，不影响主流程。

## 与历史 SDD 的关系

本包继承 [原需求](../spec.md) 中仍有效的手工筛选、七类资质、角色权限与现有页面行为。本包新增 AI 自然语言、文件匹配、自动公开资料研究和结果 Excel 导出，覆盖旧版对此类扩展的排除描述；不改写旧交付记录。

旧“Excel 仅初始化”指正式列表不提供日常批量导入按钮。本包的结果导出、对话附件分析、内部旧 Excel 核对是不同用途，均不自动触发批量覆盖导入。

历史文档中的 1283 家等数字来自既往部署证据，不能直接当成本轮数量。本轮 AI-T01 已独立核对用户随后提供的原名录并接入所属本地空库，实际得到1283个规范企业名称；这与历史数字相同，但证据来自本轮逐行核账。原历史官网研究和人工维护数据库尚未定位，当前目录下的试运行数据库也不能代表该历史库。
